## 📖 Описание проекта

**Фишинг-Детектив** — это консольная обучающая игра, которая помогает
пользователям в интерактивной форме научиться распознавать признаки
фишинга: подозрительные адреса отправителей, срочные требования,
поддельные ссылки, запросы персональных данных и т. д.

Программа включает **два игровых режима**:

- **«Инспектор входящих»** — анализ электронных писем: фишинг или безопасно.
- **«Найди подделку»** — поиск подозрительных элементов на макете веб-страницы.

Также реализованы:
- система подсказок;
- подробные объяснения после каждого ответа;
- статистика прохождения с процентом успешности.
