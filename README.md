# Фишинг-Детектив

Обучающая игра для распознавания фишинговых писем и поддельных сайтов.

Автор: Иванюк Егор Дмитриевич  
Специальность: Кибербезопасность
Группа: КБ-241  

---

## Описание

Игра помогает пользователям в интерактивной форме научиться распознавать
признаки фишинга: подозрительные адреса отправителей, срочные требования,
поддельные ссылки, запросы персональных данных и т. д.

Программа включает два игровых режима:

- **«Инспектор входящих»** — анализ электронных писем: фишинг или безопасно.
- **«Найди подделку»** — поиск подозрительных элементов на макете веб-страницы.

Также есть система подсказок, подробные объяснения после каждого ответа
и статистика прохождения.
